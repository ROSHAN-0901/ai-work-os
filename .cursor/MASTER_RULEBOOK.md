# Work router

One job. One skill. Nothing else loads.

This is the public book. The private book has the client workstreams. Those stay offline.

| Task ID | When | Skill | Agent |
|---|---|---|---|
| `emissions-method` | Why a factor, which scope, which standard | `emissions-method` | `emissions-method` |
| `disclosure-draft` | GRI, BRSR or IFRS-style narrative from a checked model | `disclosure-draft` | `disclosure-draft` |
| `rfp-matrix` | A questionnaire or RFP that should not be answered from memory | `rfp-matrix` | `rfp-matrix` |

## Rules

1. Match the ask to one Task ID. If it matches two, ask which one.
2. Read that skill only.
3. Do not open `clients/`, `local/`, or env files. The hook blocks them.
4. Cite the standard by name and year. If the model cannot support a sentence, leave a gap. Do not fill it.
5. The person signs the number. The agent drafts.
