# Disclosure draft

## What this skill is for

A first draft of a section. The person edits. The agent does not invent the year.

## Before writing

1. Confirm the framework and the section (GRI disclosure number, BRSR principle, or IFRS S2 paragraph).
2. Use only figures that are already in the checked model. If a sentence needs a figure that is not there, write `GAP` and name the missing input.
3. Keep the client's own words where the source is a policy or a board statement. Do not polish a fact into a stronger fact.

## Shape of a section

- What the requirement asks for, in one line.
- What the model supports, with the figure and the unit.
- What is not in the model yet (`GAP`).
- A short method note: boundary, year, standard.

## Rules

- No adjective that changes the meaning of a number ("significant", "leading", "robust") unless the source says it.
- Notes and narrative follow the source document. Do not import last year's wording over this year's figure.
- One section at a time. Do not draft the whole report in one pass.

## Done when

An analyst can edit the section the night before, instead of writing it from a blank page.
